# Contributing

Thanks for considering a contribution! To keep this list useful, please follow these guidelines.

## Before submitting

- Make sure the tool is **actively maintained**.
- Check the list to avoid **duplicate entries**.
- The tool should be **genuinely useful** to YouTube creators, not a placeholder page.

## Submission format

Add your entry in the appropriate category, keeping alphabetical order within that category:

```markdown
- **[Tool Name](https://example.com)** — One factual, neutral sentence describing what it does.
```

- Keep descriptions **factual and neutral** — no superlatives ("best," "#1," "amazing"), no marketing language.
- One sentence only.
- Confirm the link works before submitting.

## Pull request checklist

- [ ] Entry is in the correct category
- [ ] Entry is placed in alphabetical order within its category
- [ ] Link is valid and working
- [ ] Description is one sentence, factual, and neutral in tone
- [ ] No duplicate entry already exists

## A note on self-submissions

Submissions should be genuinely useful tools, not pure self-promotion. If you're submitting your own product, hold it to the same standard as any other entry: accurate, neutral, and genuinely useful to the list's audience. Maintainers reserve the right to edit descriptions for neutrality, or to decline entries that read as advertising rather than a factual listing.

## New categories

If you think a new category is needed, open an issue first to discuss it before submitting a PR.
